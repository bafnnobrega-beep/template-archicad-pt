# Template Archicad PT

Template Archicad aberto para a elaboração de projetos de licenciamento em Portugal.

## Estado

Projeto em fase inicial. A estrutura e os primeiros conteúdos serão publicados neste repositório à medida que forem desenvolvidos.

## Objetivo

Cada atelier em Portugal constrói o seu próprio template a partir do zero. Este projeto pretende reunir uma base comum, atualizada e aberta, com:

- estrutura de camadas, canetas e normas de desenho
- peças desenhadas e escritas habitualmente exigidas no licenciamento
- documentação de apoio ao enquadramento regulamentar
